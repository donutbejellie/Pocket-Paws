Pocket Paws

A pastel utility calculator with whale and kitten artwork, stars, and hearts built with HTML5, CSS, and JavaScript.

What's Inside
-Basic math operations (+, −, ×, ÷, %, +/−, decimals)
-Keyboard support and a toggleable calculation history view
-Pastel whale and kittens, with stars and outlined hearts

How to Run
-Put index.html, index.css, and index.js in the same folder and open index.html in your browser.
